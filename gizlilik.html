Uygulama nedir?

EmreAI Shorts Otomasyon, Emre Üstündağ'ın yalnızca kendi YouTube kanalına video yüklemek için kullandığı kişisel bir araçtır. Herkese açık bir hizmet değildir.

YouTube API Hizmetleri

EmreAI Shorts Otomasyon, YouTube API Hizmetleri'ni kullanır. Uygulamayı kullanan kişi YouTube Hizmet Şartları'nı kabul etmiş olur. Google'ın verileri nasıl işlediği için Google Gizlilik Politikası'na bakınız.

Hangi Google verilerine erişilir?

Uygulama, Google OAuth ile verilen YouTube Data API v3 iznini yalnızca şu amaçla kullanır: geliştiricinin kendi kanalına video yüklemek ve yüklenen videonun başlık, açıklama ve etiket bilgilerini ayarlamak.

  • Başka kullanıcıların verilerine erişilmez.
  • İzleyici, yorum, abone veya kişisel veri toplanmaz.

Veriler nerede saklanır?

OAuth erişim anahtarları yalnızca geliştiricinin kendi bilgisayarında çalışan otomasyon yazılımında (n8n) saklanır. Hiçbir veri sunucuya gönderilmez, satılmaz, üçüncü kişilerle paylaşılmaz veya reklam amacıyla kullanılmaz.

Google API Hizmetleri Kullanıcı Verileri Politikası

EmreAI Shorts Otomasyon'un Google API'lerinden aldığı bilgileri kullanması ve aktarması, Google API Services User Data Policy kurallarına, Sınırlı Kullanım (Limited Use) şartları dahil, uygundur.

Erişimi kaldırma ve veri silme

Verilen izin istenildiği zaman Google hesap izinleri sayfasından geri alınabilir.

Uygulama, YouTube'dan aldığı hiçbir veriyi (video listesi, istatistik, yorum vb.) saklamaz. Saklanan tek bilgi OAuth erişim anahtarıdır. İzin geri alındığında bu anahtar geçersiz olur ve en geç 7 gün içinde bilgisayardan silinir. Silme talebi için aşağıdaki e-posta adresine yazılabilir. Talepler 7 gün içinde yerine getirilir.

Privacy Policy (English)

EmreAI Shorts Otomasyon is a personal tool used by Emre Üstündağ solely to upload videos to his own YouTube channel. It is not a public service.

YouTube API Services: this app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

Data accessed: the YouTube Data API v3 scope granted via Google OAuth is used only to upload videos to the developer's own channel and set their title, description and tags. No data of other users is accessed; no viewer, comment, subscriber or personal data is collected.

Storage and sharing: OAuth tokens are stored only in the automation software (n8n) running on the developer's own computer. No data is sent to any server, sold, shared with third parties, or used for advertising.

EmreAI Shorts Otomasyon's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and data deletion: access can be revoked at any time at myaccount.google.com/permissions. The app does not store any data received from YouTube (no video lists, statistics or comments). The only stored item is the OAuth token; once access is revoked it becomes invalid and is deleted from the computer within 7 days. Deletion requests can be sent to the contact email below and are fulfilled within 7 days.
